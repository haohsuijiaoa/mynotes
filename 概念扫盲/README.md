# 多因素认证MFA

是一种身份验证方法，要求用户登录时提供**两种或以上、且属于不同类别的认证因子**，以证明“你是你”。它的核心不是简单多输一次密码，而是让攻击者即使窃取了密码，也难以完成登录。

```bash
##知识因子
你知道的东西，如密码、PIN、安全问题答案。
##持有因子
你拥有的东西，如手机、短信/邮件验证码、TOTP 应用、硬件令牌、智能卡、FIDO2 安全密钥。
其中，FIDO2/WebAuthn 和硬件安全密钥抗钓鱼能力更强
##生物因子
如指纹、人脸、虹膜、声纹。
##辅助/环境因子
你在哪里、什么时间、用什么设备、行为习惯等，常用于风险自适应认证。
```
