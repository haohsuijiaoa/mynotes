```powershell
net user guest /active:no
```

# 面试题

## 1，安全基线与漏洞的区别？

**相同点**：都属于扫描类产品，同属于主动安全范畴，主动安全核心是弱点管理，弱点有两类：

​	漏洞：系统自身固有的安全问题，软硬件BUG。

​	配置缺陷：也叫暴露缺陷，一般是配置方面的错误并会被攻击者利用。

**不同点**：

- 来源不同：

  - 漏洞：是供应商的技术问题，用户是无法控制的，与生俱来的。

  - 配置缺陷：配置是客户自身的管理问题，主要问题包括：账号、口令、授权、日志等方面的内容

- 检查方式不同：
  - 漏洞：黑盒测试。
  - 配置缺陷：白盒测试。
