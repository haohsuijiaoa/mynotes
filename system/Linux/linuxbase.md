# 一、文件操作

## 1，Vim指令

编辑于删除快捷键

| 快捷键   | 说明                           |
| -------- | ------------------------------ |
| x / X    | 删除当前字符 / 前一个字符      |
| dd / ndd | 删除行 / 删除 n 行（向下删除） |
| D / d$   | 删除到行尾                     |
| d0       | 删除到行首                     |
| dgg / dG | :star:删除到文件头 / 文件尾    |
| yy / nyy | 复制行 / 复制 n 行             |
